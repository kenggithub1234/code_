# YOLO11 Dataset Tool

แอปเดสก์ท็อป (Windows / macOS / Linux) สำหรับสร้าง dataset และเทรนโมเดล YOLO11 แบบครบวงจร
ใช้ PyQt5 + OpenCV + Ultralytics เข้าถึงกล้อง USB, ไฟล์วิดีโอ และเทรนโมเดลบนเครื่องโดยตรง

## ฟีเจอร์ (4 แท็บ)

### 1. บันทึกวิดีโอจากกล้อง USB
เลือกกล้อง → ดูพรีวิวสด → ปุ่ม บันทึก / พัก / หยุด → ได้ไฟล์ `.mp4`
(มีระบบตรวจสอบว่ากล้องส่งภาพได้จริงก่อนใช้งาน พร้อมคำแนะนำแก้ปัญหาถ้าไม่มีสัญญาณภาพ)

### 2. Label สำหรับ Object Detection
- **แหล่งข้อมูล**: โหลดได้ทั้ง 3 แบบ ใช้งานเหมือนกันหมด (นำทาง/วาดกรอบ/บันทึก/auto-label ทำงานแบบเดียวกัน):
  - "โหลดวิดีโอ" - เหมือนเดิม เลื่อนดูทีละเฟรมจากวิดีโอ
  - "โหลดรูปภาพ (หลายไฟล์)" - เลือกไฟล์รูปได้หลายไฟล์พร้อมกัน (Ctrl/Shift คลิกเลือกได้)
  - "โหลดโฟลเดอร์รูปภาพ" - เลือกทั้งโฟลเดอร์ ระบบจะดึงไฟล์ .jpg/.jpeg/.png/.bmp ทั้งหมดในนั้นมาเรียงตามชื่อไฟล์
  - เมื่อโหลดเป็นรูปภาพ ตอนบันทึกจะใช้ชื่อไฟล์เดิมของภาพ (ไม่ใช่ frame_000000) ทำให้ตามรอยกลับไปหาไฟล์ต้นฉบับได้ง่าย
- เลื่อนดูทีละเฟรม/ภาพ (ปุ่มก่อนหน้า/ถัดไป, สไลเดอร์, กระโดดข้ามได้)
- เพิ่มรายชื่อคลาส → เลือกคลาส แล้วลากเมาส์วาดกรอบบนภาพ
- **Undo**: กด Ctrl+Z หรือปุ่ม "↩ Undo" เพื่อย้อนกลับการวาด/ลบกรอบล่าสุด (ย้อนได้หลายขั้น ข้ามเฟรมได้)
- **Auto-label ด้วยโมเดลที่เทรนแล้ว**: เลือกไฟล์ `best.pt` จากแท็บเทรน (หรือโมเดลอื่น) แล้วให้โมเดลช่วยวาดกรอบให้อัตโนมัติ
  - "Auto-label เฟรมนี้" - รันเฉพาะเฟรม/ภาพปัจจุบัน
  - "Auto-label เฟรมที่เหลือทั้งหมด" - รันทุกเฟรม/ภาพที่เหลือ (ตามค่าก้าวกระโดดที่ตั้งไว้) แบบ background thread ไม่ค้าง UI มีแถบ progress และปุ่มหยุดได้
  - ติ๊ก "เฉพาะเฟรมที่ยังไม่มีกรอบ" เพื่อไม่ให้ทับกรอบที่ label มือไว้แล้ว
  - คลาสใหม่ที่โมเดลตรวจพบ (แต่ยังไม่มีในลิสต์) จะถูกเพิ่มให้อัตโนมัติ
- กด "บันทึกภาพ + label" ได้โครงสร้าง YOLO มาตรฐาน:
  ```
  dataset_detect/
    images/frame_000000.jpg ...   (หรือชื่อไฟล์เดิมถ้าโหลดจากรูปภาพ)
    labels/frame_000000.txt ...   (class x_center y_center width height แบบ normalize)
    classes.txt
    data.yaml
  ```
- **Export เป็น COCO format**: ปุ่ม "📦 Export เป็น COCO format" แปลง dataset ที่มีทั้งหมดเป็นไฟล์
  `annotations_coco.json` มาตรฐาน (images/annotations/categories) ไว้ใช้กับเครื่องมือ/เฟรมเวิร์กอื่นที่รองรับ COCO
- **Batch Resize รูปทั้ง Dataset**: ปุ่ม "🔧 Batch Resize รูปทั้ง Dataset" ปรับขนาดภาพทุกไฟล์ใน dataset
  พร้อมกันทีเดียว (รันแบบ background thread ไม่ค้าง UI มี progress bar) เลือกได้ 2 โหมด:
  - **Letterbox** (แนะนำ) - รักษาสัดส่วนภาพเดิม แล้วเติมขอบสีเทาให้เต็มขนาดเป้าหมาย (แบบเดียวกับที่ YOLO ใช้ตอน inference)
    ไฟล์ label (.txt) จะถูกคำนวณพิกัดกรอบใหม่ให้ตรงกับภาพที่ resize แล้วโดยอัตโนมัติ
  - **Stretch** - ยืด/บีบภาพให้พอดีขนาดตรงๆ (label ไม่ต้องแก้เพราะพิกัดแบบ normalize อยู่แล้วไม่เปลี่ยนตามการยืด/บีบ)
  - เลือกได้ว่าจะเขียนทับไฟล์เดิม หรือสร้างโฟลเดอร์ผลลัพธ์ใหม่ (แนะนำแบบหลัง เพื่อไม่ให้ข้อมูลต้นฉบับหาย)

### 3. Label สำหรับ Classification
- **แหล่งข้อมูล**: โหลดได้ทั้ง 3 แบบเหมือนแท็บ 2 (นำทาง/วาด crop/บันทึก/auto-label ทำงานแบบเดียวกันหมด):
  - "โหลดวิดีโอ" - เลื่อนดูทีละเฟรมจากวิดีโอ
  - "โหลดรูปภาพ (หลายไฟล์)" - เลือกไฟล์รูปได้หลายไฟล์พร้อมกัน
  - "โหลดโฟลเดอร์รูปภาพ" - เลือกทั้งโฟลเดอร์ ดึงไฟล์ .jpg/.jpeg/.png/.bmp ทั้งหมดมาเรียงตามชื่อไฟล์
  - เมื่อโหลดเป็นรูปภาพ ไฟล์ที่บันทึก (ทั้งแบบทั้งเฟรมและแบบ crop) จะใช้ชื่อไฟล์เดิมของภาพ แทน frame_000000
- เพิ่มรายชื่อคลาส
- **กำหนดคลาสให้ทั้งเฟรม**: เลือกคลาสแล้ว "กำหนดคลาสให้ทั้งเฟรมและบันทึก" (หรือกำหนดทั้งช่วงเฟรมทีเดียวด้วย Batch)
- **กำหนดกรอบย่อย (crop) ในเฟรม**: ลากเมาส์บนภาพเพื่อวาดกรอบย่อยได้หลายกรอบต่อเฟรม (เช่น มีวัตถุหลายชิ้นในเฟรมเดียว
  ต้องการจำแนกแยกกัน) แต่ละกรอบกำหนดคลาสแยกกันได้ผ่านลิสต์ "Crop ย่อยในเฟรมนี้"
- **แป้นพิมพ์ลัด 1-9**: กดเลขเพื่อกำหนดคลาส (ตามลำดับในลิสต์คลาส) อย่างรวดเร็ว
  - ถ้าเลือก crop ไว้ในลิสต์ → กำหนดคลาสให้ crop นั้นและบันทึกทันที
  - ถ้าไม่ได้เลือก crop → กำหนดคลาสให้ทั้งเฟรมและบันทึก แล้วเลื่อนไปเฟรมถัดไปอัตโนมัติ
- **Undo (Ctrl+Z)**: ย้อนกลับได้ทั้งการวาด/ลบ/กำหนดคลาสให้ crop และการกำหนดคลาสทั้งเฟรม
- **Auto-label ด้วยโมเดล Keras Classification ที่เทรนแล้ว**:
  - เลือกไฟล์โมเดล `.h5` หรือ `.keras`
  - (ไม่บังคับ) เลือกไฟล์ `labels.txt` ระบุชื่อคลาสตามลำดับ output ของโมเดล ถ้าไม่ระบุจะตั้งชื่อเป็น `class_0`, `class_1`, ...
  - เลือก preprocessing ให้ตรงกับตอนเทรนโมเดล (หาร 255 / หาร 127.5 ลบ 1 แบบ MobileNet / ไม่ทำ)
  - ตั้ง confidence ขั้นต่ำ (ผลทำนายที่มั่นใจน้อยกว่านี้จะถูกข้าม)
  - ติ๊ก "ใช้ crop ที่วาดไว้แทนการจำแนกทั้งเฟรม" เพื่อให้ auto-label จำแนกทีละ crop ที่วาดไว้แทนที่จะจำแนกทั้งภาพ
  - "Auto-label เฟรมนี้" (ทันที) หรือ "เฟรมที่เหลือทั้งหมด" (background thread + progress bar + ปุ่มหยุด)
  - คลาสใหม่ที่โมเดลเจอจะถูกเพิ่มในลิสต์อัตโนมัติ
- **แบ่ง Train/Val อัตโนมัติ**: ตั้งสัดส่วน train (ค่าเริ่มต้น 80%) แล้วกด "📊 แบ่ง Train/Val อัตโนมัติ"
  จะสุ่มแบ่งไฟล์ในแต่ละโฟลเดอร์คลาสเป็น `train/<class>/` และ `val/<class>/` (คงสัดส่วนต่อคลาสไว้ แม้จำนวนภาพแต่ละคลาสไม่เท่ากัน)
  เลือกได้ว่าจะคัดลอกไฟล์ (ปลอดภัย) หรือย้ายไฟล์ (ประหยัดพื้นที่)
- ผลลัพธ์ที่ได้:
  ```
  dataset_classify/
    cat/frame_000000.jpg ...
    dog/frame_000010.jpg ...
    dog/frame_000012_crop_0.jpg ...   (ภาพจาก crop ย่อย)
    train/cat/... , train/dog/...     (หลังแบ่ง train/val)
    val/cat/...   , val/dog/...
  ```
มีปุ่ม "🔧 Batch Resize รูปทั้ง Dataset" เช่นเดียวกับแท็บ 2 สำหรับปรับขนาดภาพทุกคลาสพร้อมกัน
(โครงสร้างโฟลเดอร์ต่อคลาสจะถูกคงไว้เหมือนเดิม)

### 4. เทรนโมเดล YOLO11 (ใหม่)
- เลือกไฟล์ `data.yaml` ที่ได้จากแท็บ 2
- เลือกโมเดลฐาน (yolo11n/s/m/l/x.pt) — ดาวน์โหลดอัตโนมัติจาก Ultralytics ครั้งแรกที่ใช้
- ตั้งค่า epochs, image size, batch size, device (เว้นว่าง = auto-detect GPU/CPU)
- กด "▶ เริ่มเทรน" — รันในพื้นหลัง (ไม่ค้าง UI) พร้อมแสดง log การเทรนแบบเรียลไทม์
- เมื่อเทรนเสร็จจะได้พาธของ `best.pt` ให้คัดลอกไปใช้ในช่อง Auto-label ที่แท็บ 2 ได้ทันที
  (workflow วนลูป: label บางส่วน → เทรน → auto-label ที่เหลือด้วยโมเดล → ตรวจแก้ → เทรนใหม่ ให้แม่นยำขึ้นเรื่อยๆ)

### 5. เทรนโมเดล Keras Classification (ใหม่)
- เลือกโฟลเดอร์ dataset (แนะนำให้ใช้ dataset ที่ผ่านปุ่ม "แบ่ง Train/Val อัตโนมัติ" จากแท็บ 3 แล้ว
  คือมีโฟลเดอร์ `train/` และ `val/` ข้างใน — ถ้าไม่มีจะ auto แบ่ง validation 20% จากโฟลเดอร์เดียวกันให้แทน)
- เลือกสถาปัตยกรรม: **MobileNetV2** (แนะนำ, transfer learning, เร็วและแม่นยำแม้ dataset เล็ก),
  **EfficientNetB0** (แม่นยำกว่าแต่ช้ากว่า), หรือ **CNN ธรรมดา** (train ตั้งแต่ต้น ไม่ต้องเน็ตแต่ต้องการข้อมูลเยอะกว่า)
- ตั้งค่า ขนาดภาพ, batch size, epochs, learning rate
- **ปรับแต่งภาพก่อนเทรน (Data Augmentation)** - เปิด/ปิดแต่ละอย่างได้อิสระด้วย checkbox:
  - **หมุนภาพ (Rotation)** - ตั้งมุมสูงสุดที่จะหมุนแบบสุ่ม (องศา)
  - **เลื่อนซ้าย-ขวา (Width Shift)** - เลื่อนภาพแนวนอนแบบสุ่ม (สัดส่วนของความกว้างภาพ)
  - **เลื่อนบน-ล่าง (Height Shift)** - เลื่อนภาพแนวตั้งแบบสุ่ม (สัดส่วนของความสูงภาพ)
  - **ปรับความสว่าง (Brightness)** - สุ่มความสว่างในช่วงต่ำสุด-สูงสุดที่กำหนด
  - ปิดทั้งหมดได้ถ้าไม่ต้องการ augmentation เลย (เช่น dataset ใหญ่พออยู่แล้ว)
- กด "▶ เริ่มเทรน" — รันในพื้นหลัง (ไม่ค้าง UI) พร้อม log และ progress bar ต่อ epoch แบบเรียลไทม์
- ผลลัพธ์ที่ได้ในโฟลเดอร์ run:
  ```
  runs_keras/train1/
    model.keras                    (ไฟล์โมเดลที่เทรนเสร็จ)
    classes.txt                    (รายชื่อคลาสตามลำดับ output ของโมเดล)
    recommended_preprocessing.txt  (จะเป็น "raw" เสมอ - preprocessing/rescaling ถูกฝังเข้าไปในตัวโมเดลแล้ว)
    training_history.png           (กราฟ accuracy/loss ตลอดการเทรน ถ้าติดตั้ง matplotlib ไว้)
  ```
- นำ `model.keras` + `classes.txt` ไปใส่ในช่อง "Auto-label ด้วยโมเดล Keras" ที่แท็บ 3 ได้ทันที
  (โมเดลที่เทรนจากแท็บนี้ฝัง preprocessing ไว้ในตัวโมเดลแล้ว ให้เลือก Preprocessing เป็น
  "ไม่ทำ (โมเดลมี Rescaling อยู่แล้ว)" เสมอ ไม่ต้องเดาว่าใช้สถาปัตยกรรมไหน)
- **ความเสถียร**: ใช้ label แบบ integer (ไม่ one-hot) คู่กับ `sparse_categorical_crossentropy` ซึ่งเป็นค่าเริ่มต้นของ
  `image_dataset_from_directory` และผ่านการทดสอบจริงแล้วว่าใช้งานได้ตรงไปตรงมาที่สุด, เปิดใช้ `.cache().shuffle().prefetch()`
  บน dataset เพื่อความเร็ว, และปิด log ที่ไม่จำเป็นของ TensorFlow ตั้งแต่ต้น

## วิธีติดตั้ง

ต้องมี Python 3.9+ และมีกล้อง USB ต่อกับเครื่อง (สำหรับแท็บ 1)

```bash
cd yolo_dataset_tool
python -m venv venv
source venv/bin/activate      # Windows ใช้: venv\Scripts\activate
pip install -r requirements.txt
```

หมายเหตุ: `ultralytics` (ใช้สำหรับแท็บเทรนและ auto-label) มีขนาดค่อนข้างใหญ่และจะดึง PyTorch มาด้วย
ถ้าต้องการ GPU (CUDA) ให้ติดตั้ง PyTorch เวอร์ชัน CUDA ที่ตรงกับการ์ดจอก่อนตาม
https://pytorch.org/get-started/locally/ แล้วค่อย `pip install ultralytics`

## วิธีรัน

```bash
python main.py
```

## เวิร์กโฟลว์ที่แนะนำ

1. บันทึกวิดีโอตัวอย่างจากกล้อง USB (แท็บ 1)
2. Label object detection ด้วยมือสัก 50-100 เฟรมแรก (แท็บ 2)
3. เทรนโมเดลเบื้องต้นด้วย epoch น้อยๆ เช่น 30-50 (แท็บ 4)
4. กลับมาแท็บ 2 โหลด `best.pt` ที่เพิ่งเทรน แล้วใช้ Auto-label ช่วย pre-label เฟรมที่เหลือ
5. ตรวจสอบ/แก้ไขกรอบที่ auto-label ให้ถูกต้อง (ลบ/วาดใหม่/Undo ได้)
6. เทรนใหม่ด้วย dataset ที่ใหญ่และแม่นยำขึ้น ทำซ้ำข้อ 4-6 จนพอใจ
7. (ถ้าต้องการ) Export เป็น COCO format เพื่อใช้กับเครื่องมืออื่น

## หมายเหตุอื่นๆ

- ไฟล์วิดีโอที่บันทึกใช้ codec `mp4v` ถ้าเปิดไฟล์ไม่ได้ในบางโปรแกรม
  ลองแปลงเพิ่มด้วย ffmpeg: `ffmpeg -i input.mp4 -c:v libx264 output.mp4`
- ในแท็บ Label ถ้าลบคลาสออกจากลิสต์ กรอบเดิมที่เคยผูกกับ id นั้นจะยังเก็บ id เดิมไว้
  (ไม่ได้ลบข้อมูลกรอบทิ้ง) แนะนำให้ตั้งชื่อคลาสให้ครบก่อนเริ่ม label จริงจัง
- ปุ่ม "ก้าวกระโดด" ใช้ข้ามเฟรมทีละ N เฟรม เหมาะกับวิดีโอความยาวมากที่ไม่จำเป็นต้อง label ทุกเฟรม
- โครงสร้างโฟลเดอร์ที่ได้จากแท็บ 2 พร้อมใช้เทรนกับ Ultralytics YOLO11 ได้ทันที เช่น
  `yolo detect train data=dataset_detect/data.yaml model=yolo11n.pt epochs=100`
  (คำสั่งเดียวกันนี้คือสิ่งที่แท็บ 4 รันให้อัตโนมัติผ่าน GUI)
